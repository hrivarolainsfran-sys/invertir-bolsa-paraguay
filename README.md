# Invertí en Bolsa Paraguay

Guía educativa e interactiva para aprender a invertir en la Bolsa de Valores de Paraguay desde cero.

## Contenido

- Cómo funciona el mercado: BVA, Superintendencia de Valores (BCP), Casas de Bolsa, emisores e inversionistas. Mercado primario y secundario.
- Guía paso a paso para empezar a invertir.
- Casas de Bolsa: servicios, checklist para elegir y directorio informativo.
- Instrumentos financieros (fondos, CDA, bonos, acciones, reportos, futuros) con filtros y comparador.
- Simulador de inversión en PYG y USD con gráfico de crecimiento.
- Test de perfil de inversionista con cartera de ejemplo.
- Glosario con buscador y preguntas frecuentes.

## Archivos

- `index.html`: la página lista para abrir en el navegador o publicar con GitHub Pages. Usa React, Tailwind CSS, Lucide React y Recharts desde CDN.
- `App.jsx`: el código fuente React (JSX) de la aplicación.

## Ver la página

Abrí `index.html` en el navegador, o activá GitHub Pages en **Settings → Pages → Deploy from a branch → `main` / root**.

## Aviso legal

Contenido exclusivamente educativo e informativo. No constituye asesoría financiera ni recomendación de compra o venta. Las tasas, montos y entidades mencionadas son ilustrativas: verificá siempre la información vigente en el Banco Central del Paraguay (bcp.gov.py) y la Bolsa de Valores de Asunción (bva.com.py).
